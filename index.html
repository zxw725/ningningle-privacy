更新日期：2026年10月19日
生效日期：2026年10月19日
适用范围：拧拧乐 Android 应用（包名 com.ningningle.game）

拧拧乐由庄孝旺（个人开发者）提供。本政策说明游戏处理信息的方式，以及您可以作出的选择。有关隐私的问题或请求，请联系 1981606396@qq.com。

一、游戏进度和设备本地数据

游戏将关卡进度、收藏、成绩、昵称和音效等设置保存在您的设备上，用于恢复进度和提供游戏功能。当前版本不要求注册游戏账号，不提供游戏进度云同步，游戏内排行榜记录保存在本机，不上传至开发者的排行榜服务器。不同设备之间不会自动同步。

您可以通过系统应用设置清除应用数据，或卸载游戏来删除本地记录。删除后可能无法恢复，请谨慎操作。

二、网络与激励广告

基础玩法和本地存档可离线使用。选择广告奖励时，应用会请求您的广告授权。同意后，应用可能在前台提前请求并缓存激励广告，以便您选择奖励时播放。拒绝授权不影响基础离线玩法，但无法领取相应广告奖励。

应用使用 TapADN（Dirichlet）广告 SDK，服务提供者为上海艾得蒽数字科技有限公司。SDK 可能处理设备型号、系统版本、OAID 等设备标识、网络状态与 IP 地址、广告展示和互动记录、崩溃及性能信息，用于提供广告、归因统计、反作弊与保障服务稳定性。相关信息由广告服务提供者依据其政策处理。应用默认关闭个性化广告。

第三方政策及详细信息：TapADN 隐私政策。不同设备和 SDK 支持情况可能影响实际获得的信息。

当前应用配置不申请精确位置、电话状态、联系人、麦克风或摄像头等权限；已关闭广告 SDK 的位置、电话状态、Wi-Fi 标识、MAC、传感器和 Android ID 等可选采集接口。网络权限用于请求和播放广告，网络状态权限用于判断网络可用性。

三、撤回授权

您可以在应用的“数据说明”页面选择“关闭广告授权”。撤回后，应用停止请求广告，并清理未播放的广告缓存；再次使用广告奖励功能时可重新选择是否同意。撤回授权不影响撤回前基于授权开展的处理，也不自动删除广告服务提供者已经依法保存的记录。

四、信息保存、共享与安全

本机游戏数据保存在应用存储空间，直到您删除数据或卸载应用。广告相关信息的保存地点、期限及其服务合作方信息请参阅广告服务提供者的隐私政策。我们不销售您的个人信息，也不主动将本地游戏进度提供给广告服务。

我们采取与应用功能相适应的措施保护数据；请保管好您的设备。使用广告功能时，必要信息会提供给上述广告服务方。本政策更新或相关功能变更涉及新的处理目的、信息种类或接收方时，我们会更新说明，并在适用情况下重新征求同意。

您可通过 1981606396@qq.com 咨询信息处理情况，申请查询、更正、删除相关个人信息或撤回同意。我们会在必要范围内核实请求身份，并依适用法律处理；对于由第三方服务独立处理的信息，可通过其政策所列渠道提出请求，我们将提供必要协助。请勿在邮件中提供密码或与请求无关的敏感资料。
